Accessibility Statement

Draft for design review. This statement describes the site's current, un-audited state. It is not a claim of certified compliance and should be revisited after a proper accessibility audit before launch.

Last updated September 20, 2026.

Our Commitment

We want anyone — regardless of ability — to be able to find the dates, book a room, and get the information they need about the Convention. We're aiming for the site to meet WCAG 2.1 Level AA, and we treat that as ongoing work, not a box that gets checked once.

What's In Place Now

  • Semantic HTML headings and landmarks, and a "Skip to content" link on every page for keyboard users.
  • Descriptive alt text on meaningful images, and social icons labeled for screen readers.
  • The interactive state map on the Travel page works by keyboard as well as mouse, and every state's data is also available as a plain table.
  • Color combinations are checked against the site's locked palette for contrast — see the palette rules on the Media page.
  • Text reflows and resizes without loss of content down to mobile widths.

Known Gaps

This is a design preview, not a finished, audited product. Specific gaps we know about:

  • The mobile "Menu" button does not yet open a keyboard- or screen-reader-accessible menu.
  • No full manual audit (screen reader pass, complete keyboard walkthrough, automated scan) has been done yet.
  • The convention mark (logo) has a known print-quality defect, tracked separately, that doesn't affect on-screen accessibility but is worth knowing about.

Feedback

If you use assistive technology and run into a problem on this site, we want to know. Email info@ac2027socal.com with the page and what happened, and we'll do our best to fix it.
